# Кию — интерактивный урок Qazline

Публичная учебная демоверсия по казахскому глаголу **кию**: объяснения, видео, иллюстрации и интерактивные упражнения.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → main → / (root).

Страница: https://gilmiyaroff.github.io/qazline_test/

Все локальные иллюстрации лежат в `assets/`. Для работы видео требуется доступ к YouTube.

В репозитории нет внутренних отчётов, CRM-выгрузок или платёжных данных Qazline.
