# Кию — интерактивный урок Qazline

Публичная учебная демоверсия по казахскому глаголу **кию**: объяснения, видео, иллюстрации и интерактивные упражнения.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → main → / (root).

Страница: https://gilmiyaroff.github.io/qazline_test/

## Игра «Собери монеты»

Отдельная страница для новичков с 20 жизненными ситуациями, подсказками, начислением 500 ₸ скидки за каждый правильный ответ (до 10 000 ₸) и финальным экраном для отправки скриншота менеджеру в WhatsApp.

Страница: https://gilmiyaroff.github.io/qazline_test/monety/

Код игры находится в одном файле `monety/index.html` — его можно адаптировать для HTML-блока Tilda. Файл использует публичный логотип `assets/qazline-logo.png` и шрифты Inter/Oswald из Google Fonts. Это клиентский прототип: результат на скриншоте не имеет серверной защиты от изменения; перед коммерческим запуском рекомендуется проверка скидки на стороне сервера или ручной регламент подтверждения.

Все локальные иллюстрации лежат в `assets/`. Для работы видео требуется доступ к YouTube.

В репозитории нет внутренних отчётов, CRM-выгрузок или платёжных данных Qazline.
